This table supplies licence evidence for pipeline tools selected by binder profiles and adjacent tools named in the tool roster. It supports tool-selection gates without defining redistribution policy.

This table is not legal advice. Confirm the exact release, model artifact, deployment method, and applicable third-party terms with qualified counsel before commercial use or redistribution.

Lookups were completed on 2026-08-23. `MISSING` indicates that the lookup found no source stating the value.

Each row names the documents behind its values. Most name the publisher's own LICENSE file, README, or licensing page. Where a row names the Claude Science platform snapshot or another page in this skill, the value rests on what that record declares rather than on a direct read of the publisher's terms.
