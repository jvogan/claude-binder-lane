# Source citations

Use the linked publisher prompt, report, model card, licence, or code for claims about an external tool. Shipped paths in `catalog.json` carry the `(SHIP)` marker and can be checked inside this skill. The [tool licence guide](tool-licences.md) links upstream terms for selected tools; Claude Science checks the current terms for the intended use.

A recorded run is evidence for its named input, route, and result. The [measurement evidence](measurement-evidence.md) page identifies which observations have supporting artifacts here. Use provider job receipts and model revisions from the current campaign for its reported cost and predictions.
